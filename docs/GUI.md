# GUI

Start:

```bash
PROJECT_ROOT="$PWD" \
PYTHON_BIN="$PWD/.venv_phase4/bin/python" \
./commands/gui/RUN_SORTER_GUI.command
```

Use:

- Preview a ZIP or folder.
- Listen to Review items.
- Select the correct taxonomy folder.
- Apply training.
- Re-run the preview.

Approved corrections enter the durable, source-blind neural inbox. The GUI
rebuilds versioned CLAP prototypes first and refreshes transitional memory lanes
second. Exact approved audio may be remembered; generalized category ownership
stays disabled until calibration and held-out gates pass. Unknown
cross-family conflicts go to Review.

For large inputs, the queue renders 200 rows at a time and downloads only new
row updates. **Stop & Keep Results** preserves completed sounds as a normal
review session. **Cancel** abandons the active run.

What the clues mean:

- **Your trained memory:** Aaron's local examples; may own a folder.
- **CLAP broad hearing:** pretrained family evidence; may block a strong contradiction.
- **CLAP detailed suggestions:** experimental advice only.
- **PANNs broad events:** independent pretrained events; may support memory or force Review.
- **Neural result:** says which lane controlled the proposal.

CLAP and PANNs listen to decoded audio. Paths are used only to open and copy
files. A relabel that conflicts with a locked human seed requires the same
choice twice; the training result tells you when confirmation is pending.

The selected-file panel shows the decision and one short reason. Open **Why
did it do this?** for plain evidence or **Technical details** for the full
trace. Adding new queue rows does not close those sections.

## Learning Center

Use **Open Learning Center** for cluster-first training:

1. Load a cluster review pack.
2. Listen to the representative examples.
3. Choose a category and approve the safe core.
4. Import approved audio separately.
5. Build one updated neural brain after the review session.

Technical scores and risky actions stay collapsed. The coverage view lists
every canonical category, including empty categories, and says what evidence is
missing. Confidence Learning reports real reviewed counts; it never invents a
confidence score when the corpus is too small.
