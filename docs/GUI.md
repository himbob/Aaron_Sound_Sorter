# GUI

Start:

```bash
PROJECT_ROOT="$PWD" \
PYTHON_BIN="$PWD/.venv_phase4/bin/python" \
./commands/gui/RUN_SORTER_GUI.command
```

Use:

- Preview a ZIP or folder.
- Listen to Review items.
- Select the correct taxonomy folder.
- Apply training.
- Re-run the preview.

Approved corrections enter the durable, source-blind neural inbox. The GUI
rebuilds versioned CLAP prototypes first and refreshes transitional memory lanes
second. Known compatible CLAP neighborhoods may own a proposal; unknown
cross-family conflicts go to Review.

What the clues mean:

- **Your trained memory:** Aaron's local examples; may own a folder.
- **CLAP broad hearing:** pretrained family evidence; may block a strong contradiction.
- **CLAP detailed suggestions:** experimental advice only.
- **PANNs broad events:** independent pretrained events; may support memory or force Review.
- **Neural result:** says which lane controlled the proposal.

CLAP and PANNs listen to decoded audio. Paths are used only to open and copy
files. A relabel that conflicts with a locked human seed requires the same
choice twice; the training result tells you when confirmation is pending.
