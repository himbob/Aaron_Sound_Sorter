# Family order policy: Drums and Instruments before abstract FX

FX is the broadest and most abstract top-level family. It can describe transition motion, impacts, glitches, designed noise, formant effects, and strange hybrid material. Because FX is so broad, it can accidentally swallow valid drums and instruments if the arbiter lets abstract FX evidence compete too early.

The intended policy is:

```text
1. Check hard integrity and broken/tiny audio.
2. Resolve structure and role.
3. Consider Drums and Instruments before broad FX when measured evidence supports them.
4. Use FX only when concrete FX authority exists, or when Drum/Instrument evidence is weak or contradicted.
5. Never let broad FX become a vacuum for valid instruments or drums.
```

Concrete FX authority can include strong measured transition motion, designed FX motion, blip/beep UI evidence, glitch/stutter evidence, impact/sweep/riser/drop evidence, or other calibrated FX-specific support. Generic weirdness is not enough by itself.

This policy should be enforced through measured evidence, claim contracts, and decoy tests. Do not implement it by hiding categories or using source names.
